# راه‌اندازی Claude Code با بات بله

این نسخه از upstream در commit `164afc1b9d3cb8cc37abd3c930cfb897257c4af9` گرفته شده است.

## اجرا

از پوشه پروژه:

```sh
python3 -m venv .venv
.venv/bin/pip install -e .
cp .env.bale.example .env
```

در `.env` توکن و نام کاربری بات بله، شناسه عددی خودت در بله را در
`ALLOWED_USERS` و مسیر مجاز پروژه‌ها را در `APPROVED_DIRECTORY` قرار بده.
نام متغیرهای `TELEGRAM_BOT_TOKEN` و `TELEGRAM_BOT_USERNAME` برای سازگاری با
upstream حفظ شده؛ مقدارشان مربوط به بات بله است.

Claude Code باید نصب و احراز هویت شده باشد (`claude auth login`)؛ یا
`ANTHROPIC_API_KEY` را تنظیم کن. سپس:

```sh
.venv/bin/claude-telegram-bot
```

در بله به بات `/start` بفرست و بعد درخواستت را بنویس. برای شروع گفتگوی جدید
از `/new` استفاده کن. برنامه باید روی کامپیوتر یا سرور روشن بماند.

## سازگاری

- `BOT_PLATFORM=bale` آدرس API و دانلود فایل را به `tapi.bale.ai` می‌برد.
  آدرس‌های سفارشی با `BOT_BASE_URL` و `BOT_BASE_FILE_URL` قابل تنظیم‌اند؛
  این مقدارها باید بدون توکن و بدون اسلش انتهایی باشند.
- پاسخ HTML در مرز API به متن ساده تبدیل می‌شود؛ محتوای کد و مقصد لینک‌های
  وب حفظ می‌شود. این تبدیل شامل پیام، ویرایش، زیرنویس، آلبوم و اعلان است.
- ReplyParameters کتابخانه به `reply_to_message_id` تبدیل می‌شود.
- ثبت منوی `setMyCommands` برای بله انجام نمی‌شود؛ دستورات متنی برقرارند.
- پیش‌نویس تدریجی و تاپیک پروژه پشتیبانی نمی‌شوند؛ فعال‌کردن آن‌ها در حالت
  بله خطای تنظیمات می‌دهد. مقدار هر دو در فایل نمونه false است.
- دریافت پیام به صورت پیش‌فرض long polling است. فیلدهای مخصوص تلگرام از
  درخواست‌های polling و webhook حذف می‌شوند. برای webhook باید HTTPS و پورت
  پشتیبانی‌شده بله را فراهم کنی؛ برای استفاده محلی polling پیشنهاد می‌شود.
- درخواست‌های بله مستقیماً ارسال می‌شوند و HTTP_PROXY/HTTPS_PROXY را به ارث
  نمی‌برند؛ تنظیمات پروکسی Claude جداست.
- احراز هویت کاربران و محدودیت مسیر و ابزارها از upstream حفظ شده است.

## اعتبارسنجی

تست‌ها با API شبیه‌سازی‌شده، URLها، پیام و Reply، دکمه‌های inline، فایل، آلبوم،
callback و راه‌اندازی بدون ثبت منو را بررسی می‌کنند. تست زنده با توکن واقعی
بله و اجرای Claude باید پس از تنظیم اعتبارنامه‌های خودت انجام شود.

مرجع API: https://docs.bale.ai/
